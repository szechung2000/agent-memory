Design choices and boundaries

01 · Repeatable data

32 synthetic CMBS source documents and 45 labeled questions across direct, multi-document, temporal, unanswerable, and corrected-data cases.

02 · Fair A/B comparison

Both variants start from the same 20 retrieved candidates. BM25 changes their order; labels are used only after retrieval to score recall@5, recall@10, and support coverage.

03 · Citation safety

The cited-answer example uses a scripted generator and the production quote verifier. A source ID must exist in retrieval, and the quote must occur in that source. Quote matching does not prove logical entailment.

04 · Honest limitations

Hash embeddings are a deterministic local fallback, not strong semantic embeddings. The browser demo makes no live LLM calls and is not a production accuracy or security claim.
